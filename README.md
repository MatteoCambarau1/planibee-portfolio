# PlaniBee

> A cross-platform personal finance application designed and developed from the ground up.

PlaniBee helps users organize their monthly income, expenses, budgets, and savings goals through a simple and consistent experience across Web, iOS, and Android.

This repository is a public portfolio showcase. The production source code is maintained in private repositories.

[Visit the website](https://planibee.com) · [Download on the App Store](https://apps.apple.com/it/app/planibee/id6803944020) · [Get it on Google Play](https://play.google.com/store/apps/details?id=com.planibee.app)

## About the project

PlaniBee started as an idea for making personal budgeting easier to understand and maintain.

I designed and developed the complete product, including:

- the responsive web application;
- the native iOS and iPadOS application;
- the native Android application;
- the backend services and API integration;
- authentication and user account management;
- data synchronization across platforms;
- the visual identity and user experience;
- App Store and Google Play publication.

The three clients share the same product principles and business logic while following the conventions and interaction patterns of each platform.

## Built from the ground up

Each platform was implemented as a dedicated software project:

- **iOS and iPadOS:** developed natively with Swift and SwiftUI;
- **Android:** developed natively with Kotlin and Jetpack Compose;
- **Web:** developed as a responsive browser-based application;
- **Backend:** custom APIs supporting authentication, user data, budgets, expenses, and savings goals.

The interfaces, navigation flows, data models, validation rules, and platform integrations were designed specifically for PlaniBee.

## Main features

### Monthly budgets

Users can define their monthly income and distribute it among customizable spending categories.

PlaniBee compares planned amounts with actual expenses and provides an immediate overview of the remaining budget.

### Expense tracking

Expenses can be recorded with:

- amount;
- category;
- date;
- description;
- associated monthly budget.

Past and future months can be managed independently.

### Savings goals

Users can create savings goals, define a target amount and deadline, and monitor their progress over time.

PlaniBee calculates an indicative monthly contribution to help users understand the path toward each goal.

### Spending analysis

Charts and summaries help users compare planned and actual spending and understand how their habits change over time.

### Cross-platform experience

The same account and financial information are available through the Web, iOS, iPadOS, and Android applications.

The interface is adapted to each platform instead of simply embedding the website inside a mobile container.

### Kimi assistant

PlaniBee includes Kimi, an in-app assistant that helps users understand the application and its features.

Kimi is designed as a product guide. It does not provide financial, tax, or investment advice.

### Additional capabilities

- customizable currencies and categories;
- CSV data export;
- biometric and device authentication where supported;
- Italian and English interfaces;
- illustrated onboarding and contextual guidance;
- responsive layouts for different screen sizes.

## Engineering approach

Developing PlaniBee required coordinating several independent applications around a shared product model.

Some of the main engineering areas included:

- defining consistent data models across multiple platforms;
- implementing secure authentication and session handling;
- synchronizing user data through backend APIs;
- reproducing the same business rules in different client environments;
- supporting monthly and historical budget states;
- handling validation and error states consistently;
- creating responsive and accessible interfaces;
- integrating native platform capabilities;
- preparing and publishing production releases.
